Un module AzerothCore pour **Conquest of Azeroth** (CoA) : les classes classiques – guerrier, paladin, chasseur, voleur, prêtre, chaman, mage, démoniste et druide – à côté des 21 classes de CoA, pour les joueurs et pour les bots aléatoires.

CoA joue les classes classiques comme le faisaient les royaumes **Warcraft Reborn** d’Ascension (leurs sorts, maîtres et talents Reborn), mais seulement sur un royaume qui n’offre rien d’autre. Ce module réunit les deux : un royaume CoA propose aussi les classes classiques, chaque race peut jouer chacune d’elles, et le patch client les affiche à la création du personnage. Les classes proposées se règlent dans `ClassicClasses.Classes`.

## Installation

Le plus simple avec [AFK Realm](https://github.com/aspollon/AFK-Realm) : *Modules → Gérer les modules* ajoute le module, recompile le serveur et apporte tout le nécessaire ; la page de configuration du module est en français. Sans AFK Realm : voir le README anglais.

Les textes qu’AFK Realm affiche de ce module sont traduits dans `lang/`.
