# mod-classic-classes

*简短版——完整说明见[英文 README](README.md)。*

一个用于 **Conquest of Azeroth**（CoA）的 AzerothCore 模块：经典职业——战士、圣骑士、猎人、潜行者、牧师、萨满祭司、法师、术士和德鲁伊——与 CoA 的 21 个职业并存，玩家和随机机器人都可使用。

CoA 会像 Ascension 的 **Warcraft Reborn** 服务器那样运行经典职业（其 Reborn 法术、训练师和天赋），但只在不提供其他职业的服务器上。本模块把两者结合起来：CoA 服务器也提供经典职业，每个种族都能选择其中任意职业，客户端补丁会在角色创建界面显示它们。提供哪些职业在 `ClassicClasses.Classes` 中设置。

## 安装

最简单的方式是使用 [AFK Realm](https://github.com/aspollon/AFK-Realm)：在“模块 → 管理模块”中添加本模块，它会重新编译服务器并带上所需的一切；本模块的设置页面提供简体中文。不使用 AFK Realm：请参阅英文 README。

AFK Realm 显示的本模块文本已翻译在 `lang/` 中。
