Um módulo do AzerothCore para o **Conquest of Azeroth** (CoA): as classes clássicas – guerreiro, paladino, caçador, ladino, sacerdote, xamã, mago, bruxo e druida – ao lado das 21 classes do CoA, para jogadores e para os bots aleatórios.

O CoA joga as classes clássicas como faziam os reinos **Warcraft Reborn** da Ascension (feitiços, instrutores e talentos Reborn), mas só num reino que não oferece mais nada. Este módulo junta as duas coisas: um reino do CoA oferece também as classes clássicas, toda raça pode jogar qualquer uma delas, e o patch de cliente as mostra na criação do personagem. Quais classes existem fica em `ClassicClasses.Classes`.

## Instalação

O mais fácil é com o [AFK Realm](https://github.com/aspollon/AFK-Realm): *Módulos → Gerenciar módulos* adiciona o módulo, recompila o servidor e traz tudo o que é preciso; a página de configuração do módulo está em português. Sem o AFK Realm: veja o README em inglês.

Os textos que o AFK Realm mostra deste módulo estão traduzidos em `lang/`.
