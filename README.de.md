Ein AzerothCore-Modul für **Conquest of Azeroth** (CoA): die klassischen Klassen – Krieger, Paladin, Jäger, Schurke, Priester, Schamane, Magier, Hexenmeister und Druide – neben den 21 Klassen von CoA, für Spieler und für die Zufallsbots.

CoA spielt die klassischen Klassen so, wie es Ascensions **Warcraft-Reborn**-Realms taten (ihre Reborn-Zauber, Lehrer und Talente), aber nur auf einem Realm, der nichts anderes anbietet. Dieses Modul bringt beides zusammen: Ein CoA-Realm bietet auch die klassischen Klassen an, jede Rasse kann jede von ihnen spielen, und der Client-Patch zeigt sie in der Charaktererstellung. Welche Klassen es gibt, steht in `ClassicClasses.Classes`.

## Installation

Am einfachsten mit [AFK Realm](https://github.com/aspollon/AFK-Realm): *Module → Module verwalten* fügt das Modul hinzu, baut den Server neu und bringt alles Nötige mit; die Einstellungsseite des Moduls ist auf Deutsch. Ohne AFK Realm: siehe das englische README.

Die Texte, die AFK Realm von diesem Modul zeigt, liegen übersetzt in `lang/`.
