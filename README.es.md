*Versión breve: la descripción completa está en el [README en inglés](README.md).*

Un módulo de AzerothCore para **Conquest of Azeroth** (CoA): las clases clásicas – guerrero, paladín, cazador, pícaro, sacerdote, chamán, mago, brujo y druida – junto a las 21 clases de CoA, para jugadores y para los bots aleatorios.

CoA juega las clases clásicas como lo hacían los reinos **Warcraft Reborn** de Ascension (sus hechizos, instructores y talentos Reborn), pero solo en un reino que no ofrece nada más. Este módulo une ambas cosas: un reino de CoA ofrece también las clases clásicas, cada raza puede jugar cualquiera de ellas y el parche de cliente las muestra al crear el personaje. Qué clases hay se fija en `ClassicClasses.Classes`.

## Instalación

Lo más sencillo es con [AFK Realm](https://github.com/aspollon/AFK-Realm): *Módulos → Gestionar módulos* añade el módulo, vuelve a compilar el servidor y trae todo lo necesario; la página de configuración del módulo está en español. Sin AFK Realm: consulta el README en inglés.

Los textos que AFK Realm muestra de este módulo están traducidos en `lang/`.
