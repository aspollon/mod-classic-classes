Модуль AzerothCore для **Conquest of Azeroth** (CoA): классические классы – воин, паладин, охотник, разбойник, жрец, шаман, маг, чернокнижник и друид – рядом с 21 классом CoA, для игроков и для случайных ботов.

CoA играет классическими классами так, как это делали миры **Warcraft Reborn** от Ascension (их заклинания, учителя и таланты Reborn), но только в мире, где больше ничего нет. Этот модуль объединяет оба варианта: мир CoA предлагает и классические классы, любая раса может играть любым из них, а клиентский патч показывает их при создании персонажа. Доступные классы задаются в `ClassicClasses.Classes`.

## Установка

Проще всего с [AFK Realm](https://github.com/aspollon/AFK-Realm): «Модули → Управление модулями» добавляет модуль, пересобирает сервер и приносит всё нужное; страница настройки модуля на русском. Без AFK Realm: см. английский README.

Тексты, которые AFK Realm показывает для этого модуля, переведены в `lang/`.
